# Editable HEVC buffer limits
Version: 0.1. Date: 2026-10-03. D-092 / R-059 prerequisite. Status: focused/generated/final local regression and optimized build passed; native saved-intent walkthrough passed.

Software HEVC can opt into Suggested or Custom VBV limits. Suggested peak rate and buffer capacity derive from bounded output raster, matching declared frame rate and published HEVC Main/Main 10 level limits. Main tier favors compatibility; High tier permits more headroom where supported. For 3840 by 2160 at 24000/1001, the candidate is level 5: Main 25000 kb/s and 25000 kbit, or High 100000 kb/s and 100000 kbit. These are decoder limits, not estimates of the scene's required bitrate or subjective quality. High tier does not certify any playback device.

Turning off Suggested prefills the displayed values into independent manual fields. Manual values remain fixed when geometry changes; planning chooses a level that fits them instead of clamping. Invalid pairs, targets exceeding a manual peak, missing/variable declarations, unsupported raster/limits and another codec/engine are refused. Nothing silently ignores the stored setting. Turning VBV off restores unrestricted encoding; older recipes default to off. This does not enable or qualify Dolby Vision. Future Dolby admission must also validate its own level limits.

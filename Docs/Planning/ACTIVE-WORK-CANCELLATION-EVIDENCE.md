The selected preparation path now checks each reader's Foundation close call once. It still joins the existing process-termination and two reader obligations before returning. There is no release or recovery interface.

The renderer attempts output and input closes after its body stops, including after cancellation. It attempts both despite the first refusal and preserves the original body error. Uncertain handles are retained in concrete renderer storage. Preparation recognizes the existing shared ownership marker and preserves its scratch folder. A close failure is not permission to delete files.

# P8.1 native mux and generated Batch integration

The existing Batch controller now has a generated-only P8.1 path that transforms the reviewed P7 metadata, retains exact base-layer packet bytes and original clocks, runs the full output verifier and exclusively publishes the verified artifact. Public P8.1 admission remains unavailable. Native consent, queue, result and Reveal acceptance still need qualification; all M1-M5 remain open.

Native extraction emits the original NAL bytes without injecting configuration parameter sets. The bounded mux pairs transformed packets by ordinal retained-base-layer equality, copies original block headers and timestamps, and writes the exact admitted P8.1 declaration. It recalculates EBML sizes, removes stale seek/cue/position/CRC fields, checks the exact container parent hierarchy and preserves in-band parameter sets. Reordered or ambiguous source timestamps refuse. Synthetic framing tests cover corruption, short reads, cancellation and identical shared-error propagation; they do not establish decodable Dolby semantics.

The same Batch owner retains every positive native source, candidate and output descriptor before validation can fail. It joins the exact mux task before eligible checked closes. Tool output is created exclusively through the pinned stage directory, then supplied as an inherited writable descriptor: the converter writes `/dev/fd/0` and FFmpeg writes `pipe:0`. The tool runner borrows this handle without closing it; existing callers still receive null input. Every failure retains the concrete owner, scopes, stage and any unconsumed descriptors. Successful settlement is followed by size, identity, stage and cancellation checks before one consumed close. This does not establish universal descendant settlement or immutable input/tool binding.

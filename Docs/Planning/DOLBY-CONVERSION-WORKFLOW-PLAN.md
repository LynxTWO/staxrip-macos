# Dolby Vision conversion workflow target

Owner-directed next user-facing target; sole root integration owner. Working app behavior and verified output close this unit. Resource prerequisites and test counts do not.

## Input and separate output contracts

Use generated HEVC Main 10, 3840 x 2160, 24000/1001 frames per second, Dolby Vision profile 7/level 6/compatibility ID 6, MEL-style metadata, BT.2020/PQ and CM 2.9. A profile declaration alone does not prove MEL, effective per-picture metadata or a complete source association. No owner movie processing or repeat of the completed owner association.

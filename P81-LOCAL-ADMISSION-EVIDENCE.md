# Local P8.1 copy admission

The dedicated Batch and preliminary queue-review paths now accept the narrow P7 MEL to P8.1 unchanged-video route in both build configurations. Generic encoding still rejects this intent. Journal isolation no longer determines conversion eligibility: its existing fresh-directory, ownership, permissions, symlink and absent-journal checks apply in release builds too; an invalid requested journal disables execution without falling back to normal recovery.

Every job still requires source-specific enhancement-loss consent and the existing complete native packet, timing, metadata, decoded-frame and final published-artifact checks. The supported subset is one 4K Main10 video-only MKV track, 24000/1001 reported rate, top-left chroma, PQ/BT.2020, strictly increasing packet-to-picture association, and the exact supported P7 MEL/CM2.9 identity mapping and Level1/5/6 metadata schema. Other metadata, tracks, reordered pictures and edited or reencoded routes remain refused. Base-layer bytes are retained; enhancement data is removed with acknowledgement.

This is a local structural conversion claim. Same-lineage metadata and decoded-base-layer checks do not establish independent Dolby appearance, playback or calibrated rendering. Developer ID/public distribution, FEL, edits, original archival workflows, genuine SDR and the five larger milestones remain separate open work.

The existing concrete Batch owner, uncertainty retention, tool/descriptor lifetimes and exclusive publication code are unchanged. Historical generated cancellation, short-write, close, substitution, source-change and collision evidence remains applicable. The generated start helper now calls the same ordinary route without an admission bypass.

The optimized, non-DEBUG app completed an actual generated-only GUI journey: reopen saved settings without consent, reselect the source, inspect all eight metadata/packet records, acknowledge enhancement loss, queue, review destination access, convert, verify and exclusively publish, display Completed, then invoke Reveal. The saved journal bound consent to the source hash and byte count. The source stayed unchanged; the published 23,491-byte output matched the staged inode and the previously qualified generated output hash. Finder selection and MKV playback were not independently confirmed. The owned app was explicitly quit and its absence observed.

Validation: 19 focused tests across three suites passed; the final ordinary run passed 716 tests across 114 suites with the same 40 opt-in skips and no warnings. An initial ordinary run failed because two UI wording edits changed a compiler input during its static-host build; that compiler diagnostic is retained. After the source was fixed in place, the final ordinary run passed without changing bounds or assertions. The explicit optimized build passed in 25.10 seconds with no warnings; strict ad-hoc app/helper signature checks passed. This is local development signing, not Developer ID or distribution trust.

The named owner-tryable local P7 MEL to P8.1 structural conversion milestone is qualified for this bounded subset. The five broader non-audio milestones remain open.

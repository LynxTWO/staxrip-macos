# Original mastering M1 numerical contract
Version: 0.1 Draft. Date: 2026-09-28.

Approved Slice 002 is active. These are the initial preregistered engineering parameters for the bounded feasibility experiment, not measured quality claims.

- Selected-speech reference pools full 400 ms energies at 100 ms hop from independently reset intervals, then applies the existing absolute/relative gate to the pool.
- Smart uses constant gain if the reference target, programme LRA and -1.5 dBTP internal margin permit it. Otherwise the original Swift planner builds a shared 20 ms gain envelope from measured momentary energy. Night uses the same architecture with stronger levelling and explicit excursion caps.
- Applied linked-envelope bounds: -36 to +12 dB; the reused limiter may add attenuation and never supplies makeup gain. Report these as pre-limiter envelope bounds, not measured total output gain. A request outside these bounds refuses rather than silently changing the target. Dynamic levelling strength starts at `1 - maximumLRA / measuredLRA`, clamped to 0 through 1; Night uses at least 0.75. Two further attempts may increase the strength and correct the measured reference offset. Three candidates maximum.
- Momentary frames align at window centre (200 ms before window end). A 500 ms future minimum anticipates reductions. Gain reduction/recovery smoothing constants: Smart 200/2000 ms, Night 20/500 ms. Interpolate dB linearly between 20 ms points. At levels below max(-55 LUFS, reference -25 LU), hold adaptive gain; no upward adaptation in these windows. Never identify that threshold as speech detection.
- The dynamic path reuses installed FFmpeg's alimiter at four-times source rate, limit -1.5 dBFS, attack 5 ms, release 50 ms, automatic makeup disabled, latency compensation enabled, then returns to the original sample rate. This is a reused peak-control component, not an original limiter or certified true-peak guarantee. Both independent measurement and a separate FFmpeg ebur128 check must accept the actual encoded candidate. The constant-gain path bypasses limiter/resampling.
- No DSP package is added. Existing FFmpeg remains a local, user-installed dependency; dependency distribution is outside this slice. Measure frame count and latency on impulses at all supported rates before accepting this reuse.
- Sources and candidates stream through owned files and bounded buffers. Before/after source hashes and fixed stream/rate/layout contracts bind a plan to its input. Imported reports are never gain authority.

M1 exit requires generated known-answer pooling, constant-gain, linked stereo, peak-limited feasibility, latency/frame-count and bounded-noise tests. Failure is investigated without widening the Slice 002 acceptance tolerances. Listening quality is an M2/M3 gate and is not inferred from M1.

Initial experiment: energy pooling, constant FLAC candidate/publication, a 30-second 20 dB transition Night candidate, and impulse latency/frame count/true peak at all five rates passed in release tests. Additional tests passed for quiet-tail non-increasing gain, phase-opposed stereo balance, silent/unconfirmed speech refusal, changed-source refusal, and constant PCM identity within two 24-bit LSBs. The quiet-tail range conflict is a verified refusal case, not a successful 3 LU master. Original preview staging uses float64 WAV to preserve over-full-scale decoded values; playback must attenuate safely. Scratch estimate includes that larger original.

M1 numerical feasibility exit: eight tests passed in 7.484 seconds (release). Independent integrated loudness/peak use the unpadded candidate; only the independent LRA pass uses 1.5 seconds of padding, matching the Swift meter tail policy. The initial padded integrated comparison was rejected and corrected without changing tolerances. Full regression, EBU, long-file, listening and native UI gates remain open.

Gain-statistics clarification before M2: the reported min/max are the exact applied Swift envelope extrema before the reused limiter. They must be labelled as such in UI and receipts. The limiter can add attenuation, so these numbers are not represented as measured total gain extrema. Its makeup is disabled; final peaks and loudness are measured independently. Characterizing the limiter's time-varying attenuation remains a verification-report limitation, not an invented statistic.

## Objective diagnosis and registered revision 7 experiment

A local export of the licensed film's 20 ms energies and retained envelopes now supports reproducible diagnostics with `scripts/diagnose-gain-planner.py`. Its zero-shift integrated and range percentiles must agree with the Swift predictor within 0.000001 LU. Constant known-energy gain and silence checks are separate. All predictions remain research evidence only.

The retained Smart envelope adds 1,240 windows to the LRA gate relative to the source; Night adds 1,340. Restricting the diagnostic distribution to source gate membership would report only 7.68/1.23 LU, versus the correct freshly gated 13.32/5.53 LU. **Do not freeze membership in the actual meter.** A +3 dB shift, clipped at the unchanged +12 dB ceiling, changes Smart to -23.52 LUFS/15.39 LU and Night to -31.83/7.56. More than half the Smart gain bins then hit the boost ceiling. These probes omit excursion constraints and are not candidate outputs or proofs of feasibility. They establish that a global correction alone worsens range and that changing membership matters; they do not establish that all possible compliant plans are infeasible.

Before implementation, register one objective experiment: remove the net predicted energy change from each iteration's range correction before adding its programme loudness correction. Compute the range-only correction per bin as before; calculate its aggregate energy ratio using the currently predicted post-gain bin energies, and subtract that ratio in dB from all range corrections. This makes the unconstrained range-only step energy-neutral before reapplying the existing constraints. Integrated relative gating and constraint projection can still change loudness, so actual fresh measurement remains mandatory. Keep revision 3 smoothing, quiet holds, caps, band width, 24 iterations, three actual renders and every acceptance limit. Run generated tests and the two unchanged film requests. If this does not pass, retain revision 3 and record the outcome; do not promote an unverified algorithm or claim global feasibility.

Revision 7 passed all 12 focused generated/recovery tests in 6.534 seconds. It brought both film predictions within the requested integrated tolerance: Smart -23.3645 LUFS and Night -30.2166 LUFS. However, range widened to 15.6372 LU and 10.3341 LU respectively, failing the unchanged 12/4 LU acceptance ceilings. No full film render or publication followed; the preflight stopped both. Revision 7 was reverted. This supports the diagnosis that the previous range correction competed with integrated correction, but energy-neutral range correction alone does not solve the gain-limited distribution problem.

Next design work must treat integrated target, gain saturation and changing range-gate membership together. Preserve quiet ambience; do not deliberately erase quiet windows or freeze gate membership to satisfy a statistic. Retain revision 3 and the open D-015 decision. A future constrained optimizer needs an explicit objective and generated sparse-background fixtures before another film trial. This is an engineering checkpoint, not an owner's listening failure or a mathematical infeasibility finding.

## Registered offline joint-objective investigation

Use the existing local energy snapshot to test a numerical optimization hypothesis outside the app. NumPy and SciPy are local research tools only; neither is an app runtime dependency. Optimize 20 ms dB gains with -36/+12 bounds. Initially fix below-floor bins to base gain to isolate foreground/background interaction. The objective combines integrated target error, short-term energy outside a band ending at target+1 LU and having width max(0.5, requested LRA-0.5), and squared adjacent-gain differences. Recompute gates and the central 10th-to-95th percentile window membership each evaluation. Use weights 10 for integrated error, 1 for mean squared band error, and 0.1 for mean squared adjacent-gain differences. Bound L-BFGS-B to 200 iterations. Check analytic gradients against finite differences on a small generated energy sequence before the film run. This relaxed model omits production look-ahead, limiter and full quiet-transition constraints; success would only justify a subsequent constrained implementation, never publication. Failure does not prove infeasibility.

The analytic gradient agreed with finite differences within 4.98e-9. The first relaxed run reached Smart -22.997/12.833 before a line-search failure at iteration 156; Night reached -32.955/6.603 at its 200-iteration limit. Neither met the fixed requests. Before the follow-up: start at constant base gain and hold the current integrated gate and central range-window selection fixed during each inner solve. Recompute both after each inner solve. Use ten outer solves of at most twenty L-BFGS-B iterations, retaining the same total bound, objective weights and gain/quiet bounds. This addresses the discontinuous optimization objective; it does not freeze the acceptance meter or permit publication based on the relaxed model.

The fixed-selection run predicted Smart -23.0000/11.0876, within the numerical request, and Night -30.0105/4.2259, still outside range. Most Night inner solves hit the iteration bound. Before a convergence characterization, increase the offline bound to ten outer solves of at most 100 inner iterations and set the projected-gradient tolerance to 1e-7. Keep all other objectives and output limits unchanged. This is a research-only convergence check; no additional audio render is authorized by the optimizer result alone.

The convergence run brought Night to -30.0044/3.9321, within the numerical request. The relaxed envelopes are not usable: the earlier 200-iteration run had maximum adjacent 20 ms changes of 2.68 dB Smart and 5.38 dB Night. Before implementation of the next research model, place centred Gaussian smoothing (500 ms radius, sigma 200 ms Smart and 80 ms Night) and the non-increasing below-floor hold inside the objective's forward model. Differentiate through both transformations. Keep below-floor raw controls fixed at base gain, all other controls within -36/+12, and the same 10 by 100 bound. Check the transformed gradient independently with finite differences. Start at constant base gain. Actual measurement must still enforce peak and Night excursions; the research model does not replace those gates.

The transformed gradient matched finite differences within 7.96e-9, and Night predicted -30.0006/3.9890. However, inspection found hold-release discontinuities: maximum adjacent changes were 5.82 dB Smart and 10.00 dB Night despite Gaussian filtering. Before the next experiment, enforce rise/fall limits in the forward model after filtering: Smart 6/24 dB per second and Night 24/60 dB per second. During below-floor holds the permitted rise is zero. Differentiate through active slope constraints and repeat the gradient check. Keep the same solver and measurement limits. These rate choices are preregistered engineering hypotheses and still require listening assessment. Clamp floating-point convolution results to the existing -36/+12 bounds before exporting research envelopes; this removes arithmetic round-off, not an expanded gain allowance.

The Gaussian/hold research Smart envelope was also rendered through the real limiter and independently measured. It failed at -24.16 LUFS/11.51 LU, versus predicted reference near -23; peak limiting is another omitted optimization effect.

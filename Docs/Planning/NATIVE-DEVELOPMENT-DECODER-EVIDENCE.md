## Need and boundary

D097 established compatible minimal LGPL development relocation and complete source
association. This unit gives the fixed C reference a native owning worker and strict
incremental stream. It does not repeat the complete owner-source run or known hardened
ad-hoc library Team-ID rejection. No decoder is bundled, no release Tool factory or app
action exists, and default Preview packaging is unchanged.

DolbyDecoderProcess.Tool has only a DEBUG development constructor. The caller explicitly
provides fixed Helpers/reference content hash, three fixed sibling Frameworks library
hashes and expected codec/format/util versions. It cannot select arbitrary library names
from media/archive content. The actual frozen five-object candidate matches D097's
private macOS14 relocation receipt. Ordinary ad-hoc development execution is distinct
from positive Developer ID, hardened library loading or distribution.

The concrete controller follows D113 POSIX mechanics without changing that reader or
general ToolRunner. A generic process adapter was rejected for this unit because the
decoder schema, sibling libraries and association limits differ. These mechanics can be
consolidated after their actual contracts and failure evidence agree.

## Owned execution and observations

One dedicated native worker owns direct child, process group, null stdin, finite source/
threads argv, minimal environment, nonblocking stdout/stderr, EOF and waitpid. It pins
no-follow regular source/executable/library descriptors, observes original path identity/
mode/size/timestamps, hashes before use and rereads full contents before return. Source
maximum1TiB, tool/library maximum32MiB each; threads only1 or4. Dylibs require read access,
not executable permission. No inherited loader override is forwarded. These observations
are not immutable snapshots, hostile same-user exclusion, native Security authentication
or proof of every dynamic image actually mapped.

Configured deadline is finite and at most120s, checked during hashing/stream work. Read
chunks16KiB, stderr refusal limit65536bytes; each JSONL line includes at most65535 non-LF
bytes and total rows at most4000002. Strict existing native integer JSON refuses duplicate/
unknown fields, floats/exponents/null/escaped strings and wrong boolean types. Header
source size/version/threads/codec versions, packet order/count/bounds, exact signed PTS,
emitted frame order/geometry/RPU digest shapes and complete counts are admitted. Only
progressive yuv420p10le constant geometry is admitted in this development scope. Codec
cropping is observed separately and never silently applied; container declarations and
display conversion remain separate. Int64.min is the FFmpeg no-PTS sentinel and refuses;
other signed PTS preserve integer values. No nanosecond conversion occurs.

A row consumer is synchronous and transient; it must not start unsettled background work.
No pictures or whole streams are retained by controller/parser. The parser retains only
its current bounded line, counters and constant geometry. Configured protocol caps are
not measurements of total native/FFmpeg memory. C reference64MiB per-allocation,16MiB
packet,2M count and4096x4096 pixel limits are not an enforced total heap ceiling.

Success requires complete framing, both pipe EOFs, joined direct child, exit zero and final
pinned source/executable/library observations. Cancellation/consumer/malformed/deadline/
nonzero/late refusal never produces a receipt. The leader remains unreaped until both
EOFs or abort so group signalling never follows an owned reap. Abort signals only the
still-owned group/PID and joins direct child before return. Uncertain group/join propagates
CompanionUnsettledOwnership; future callers must retain needed access/temporary files.
No security-scope/activity controller is integrated. Physical I/O/parser/consumer/wait
cannot be preempted. Generated pipe-holder execution ends, but portable orphan reaping,
escaped descendants and universal group cleanup are not claimed. Existing known group
EPERM is not normalized to ordinary cancellation.

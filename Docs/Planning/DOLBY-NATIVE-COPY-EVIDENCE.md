# Native Dolby base-layer copy verification

M2 consumer: the planned source inspection → HDR10 copy → verification → exclusive publication workflow. The route remains unavailable: this change closes its encoded packet/configuration comparison gap, not the decoded-frame or owning Batch gates.

`DolbyCopyNative` reads caller-provided bounded native views. Its first contract requires one total HEVC track, Matroska SimpleBlocks, an integer nanosecond clock equal to the admitted packet clock, positive DefaultDuration, and the selected P7/L6/CCID6 v1 declaration. Other track layouts, BlockGroups, lacing, invisible/discardable packets, mappings and timing transforms refuse. The declaration does not prove MEL or CM 2.9; fresh full source inspection remains necessary.

The scanner compares exact hvcC bytes and requires layer-zero VPS/SPS/PPS arrays. It preserves in-band parameter sets. It hashes every original packet and a projection that removes only NAL types 62 and 63, preserving all retained length prefixes, NAL bytes, packet boundaries and encoded order. Source packets require one RPU each and some enhancement-wrapper data overall. Output packets refuse either removed type, non-base-layer NALs, any selected mapping, or a positive MaxBlockAdditionID.

The combined `verify` entry binds both complete native packet digests to D177 timing receipts, checks explicit signed PTS/DTS/duration equality, then checks projected source against complete output. Individual payload bindings omit DTS/duration and are insufficient. Domain-prefixed fixed-width digests preserve duplicates and nonmonotonic order without an unbounded packet collection. Bounds remain one MiB read chunks, 16 MiB packets and two million packets. Read errors and shared ownership markers propagate unchanged; this scanner does not acquire or close descriptors, delete files, or publish results.

Four deterministic tests cover projection and in-band parameters, signed duplicate packet binding, changed payload/count/PTS, changed DTS/duration despite valid payload binding, leftover Dolby data/mapping, nonzero layers, malformed/truncated data, missing or surplus source RPU, clock mismatch, empty TrackOffset, cancellation, short reads and same-instance ownership uncertainty. The small synthetic NAL bodies are framing witnesses, not decodable HEVC or Dolby semantics.

Independent source review found and corrected a missing combined timing comparison and empty TrackOffset acceptance. Review is source-only, not independent execution. Existing original-preservation scanners and all historical tests remain unchanged.
